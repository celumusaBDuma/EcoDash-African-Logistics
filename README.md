# EcoDash-African-Logistics

EcoDash: African Digital Logistics &amp; Infrastructure Simulator

## Project Overview

**EcoDash** is an interactive 2D HTML5 Canvas simulation designed to model real-world logistical challenges across African environments. In South Africa, recurring **load-shedding blackouts** create critical infrastructure bottlenecks for essential services and rural microgrids.
